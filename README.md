# What does this do?
This is a simple 10x10 grid editor with 3 different visualizations:
- The default view that displays marked cells with a red X.
- The mosaic view that alternates marked cells from black to white and vice versa.
- The slip view that colors marked cells to a color I have not programed customization for yet.
